Evaluator prompt alignment

The active shadow prompt v3 was measured on development labels. It remains reference-free, but it does not yet discriminate failures.

Prompt v2 · Orq 1.0.0

Requires valid visible claims, continued conversation when benchmarks are missing, and conversation-level context. Its “unsupported data-definition” wording leaves judges to choose whether missing proof is itself failure.

Prompt v3 · Orq 1.0.1
  • Fail claims only when visible evidence materially contradicts or demonstrates them false—not merely because provenance is incomplete.
  • Grade the analytical step requested; require adjacent context only when omission makes that result misleading.
  • Let judges check claims and direct arithmetic against visible tool results without deriving a hidden ideal answer.
  • Use binary fail only when an issue can change interpretation, action, or confidence in the core result; retain minor issues in the critique.
