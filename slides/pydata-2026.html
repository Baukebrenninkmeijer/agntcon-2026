Scaling evaluation

Offline, online, continuous

Offline

Curated cases for development, alignment and comparisons.

Online

Sampled production traces reveal new failures and drift.

Continuous

Checks run on changes and repeat over time.

The criterion can move between modes only while production stays inside the slice validated by humans.

Build the eval once.
Then it guards every commit.

FIRST

Build with humans

Hard cases and edge cases. A low pass rate at the start is the point.

THEN

Guard every commit

Known behavior and core paths. Everything passes, or the commit stops.

What a failed eval teaches
the agent and the rubric

Evaluator finding
The analysis reports declining revenue.

It never explains what the CFO should decide.

Diagnosis
Two gaps, not one.

Sphere never connects analysis to decision, and the rubric never said what unsupported means.

Sphere skill update
Connect the analysis to the decision.

Explain the commercial drivers, separate evidence from assumptions, lead with the implication.

Evaluator update
Say what unsupported means.

A claim fails when the visible evidence contradicts it, not merely when proof is absent.
